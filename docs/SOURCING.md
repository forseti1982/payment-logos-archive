# Official artwork sourcing policy

Production artwork is sourced from the **brand owner only**.

## Quality order

`SVG → EPS/AI → vector PDF → PNG → WebP → JPG`

The highest-quality authoritative file wins. A lower-quality format is not promoted when an official vector master exists.

## Mandatory workflow

1. Identify the current product/acceptance identity.
2. Open the brand owner's official developer, merchant, partner or brand portal.
3. Read the current CI / trademark / logo usage rules.
4. Determine whether use requires a merchant relationship, license, approval or asset request.
5. Download the highest-quality permitted original.
6. Preserve it byte-for-byte in `assets/source/`.
7. Record source URL, retrieval date, format, variant and restrictions.
8. Validate SVG/XML security where applicable.
9. Generate wallee distribution/tile derivatives without modifying the trademark.
10. QA at real machine sizes.

## Controlled assets

A logo visible on an official website is **not automatically a distributable master**. Where the owner supplies assets only through a portal/request, the registry remains gated until that asset is legitimately obtained.

Examples:
- Garmin Pay: request official assets from Garmin.
- TWINT: merchant product logo is provided via the TWINT Business Portal.
- Alipay+: official assets are subject to the applicable authorization/license and display guidelines.

No screenshot, CSS image, search-engine result, Wikimedia file or third-party PSP repository may be substituted merely to complete the gallery.
